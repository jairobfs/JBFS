```markdown

## Cirurgia

```

## Regras de redação

- Uma linha de justificativa forte > parágrafo vago
- Incluir a **letra** quando visível na UI; se a UI não mostrar letra estável, usar o texto da alternativa
- Não copiar enunciado inteiro (resumo de tema basta), salvo pedido explícito
- Destacar conflitos MS vs. guideline internacional quando isso decidir a alternativa

## Seções típicas ENAMED (ordem observada na SPR Med)

1. Clínica Médica (~1–30)
2. Cirurgia (~31–50)
3. Pediatria (~51–70)
4. Ginecologia e Obstetrícia (~71–85)
5. Medicina Preventiva / Saúde Coletiva (~86–100)

Ajustar limites se o mapa da prova for diferente.
